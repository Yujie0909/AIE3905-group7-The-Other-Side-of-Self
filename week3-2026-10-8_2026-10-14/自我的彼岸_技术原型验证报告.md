## 三、分环节验证方案

### 3.1 T3 语音管线（Whisper + Silero VAD + GPT-4o）

**链路**：麦克风 → Silero VAD 检测说话起止 → faster-whisper 转写中文 → LLM 提取 6 维理想特征(JSON) → 构建 perfect/crack/collapse 三组图像 Prompt

**运行**：
```bash
python t3_voice/run_t3_pipeline.py
```
**产物**：`output/t3_pipeline_result.json`（含转写文本、结构化特征、3 组 Prompt）

**LLM 切换**（国内直连无忧）：`config.py` 中把 `LLM_BASE_URL` / `LLM_MODEL` 改为 DeepSeek 或通义千问即可，代码结构已完全兼容。

**端到端成功标准**：
- [ ] 对着麦克风说话，Silero 正确判定"开始/停顿结束"
- [ ] faster-whisper 输出与口语一致的中文文本
- [ ] LLM 返回合法 JSON（6 个特征字段）
- [ ] 生成 3 组图像 Prompt 并成功落盘

### 3.2 T4 FLUX 本地图像生成（FLUX.1 Schnell FP8）

提供两套后端，均可独立验证：

- **方案 A diffusers**（`FLUX_USE_FP8=True`）：Python 直连生成，适合快速验证选型效果。
- **方案 B ComfyUI**（更省显存，推荐生产）：启动本地 ComfyUI 后 `COMFYUI_API_USE=True`，脚本经 `/prompt` 提交、轮询取图。

**运行**：
```bash
# 单独验证 FLUX
python t4_flux/run_t4_flux.py --prompt "金色晨曦，海边，自由"

# 消费 T3 生成的 3 组关键帧 Prompt
python t4_flux/run_t4_flux.py --from-json output/t3_pipeline_result.json
```
**产物**：`output/t4_perfect.png` / `t4_crack.png` / `t4_collapse.png`

**成功标准**：4 步生成，单张 < 10 秒（GPU），图像符合 Prompt 意境；若 8GB 显存吃紧，手册提供 GGUF Q4 量化降级方案。

### 3.3 T2 MediaPipe 人体追踪 + TouchDesigner

**链路**：摄像头 → MediaPipe Pose 33 关键点 → 计算 arm_open / torso / raise_ratio 特征 → UDP-OSC 发送到 TouchDesigner 驱动崩塌特效。

**运行**：
```bash
python t2_mediapipe_td/pose_tracker_td.py
```
**TD 端**：新建 `OSC In` CHOP（端口 7400），或按手册路径 B/C 用 TCP 或社区插件接入。

**成功标准**：
- [ ] 摄像头中能实时检测人体并绘制 33 关键点（约实时帧率）
- [ ] 特征数值随动作合理变化（手臂张开/收拢、举手）
- [ ] TouchDesigner 能收到 `/pose/*` OSC 数据并驱动视觉

## 四、完整链路 Demo（理想态）

```
摄像头 → MediaPipe → TD(OSC)                 ┐
                                           ┼ → FLUX 生成3关键帧 → TD 投影映射 + 崩塌特效
麦克风 → Silero → Whisper → LLM(6维特征) ┘
```

交互逻辑（数据联动）：
- 姿态特征 `arm_open > 0` 且 `torso` 高 → 判定"完美"状态
- 姿态收拢 / 不舒展 → "裂隙"状态
- 姿态剧烈变化 / 语音情绪强度高 → "崩塌"状态
