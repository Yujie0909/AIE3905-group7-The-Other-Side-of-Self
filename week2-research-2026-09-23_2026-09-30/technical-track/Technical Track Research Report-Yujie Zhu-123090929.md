# 技术栈调研

## 一、技术线拆解

（一）作品呈现：《自我的彼岸》是一个单用户沉浸式交互装置，体验流程如下：

用户站在一面"镜子"前，看到的是自己的真实倒影（表世界）

系统温柔引导用户："如果没有任何限制，你希望自己成为怎样的人？"

用户用语音描述自己理想中的生活

镜面开始泛起涟漪，逐渐浮现出一个由 AI 生成的"理想世界"

用户在这个理想世界中凝视片刻

理想世界开始出现裂隙，逐渐崩塌瓦解

镜面回归平静，重新映出用户真实的自己

要实现上述体验，技术层面必须回答四个问题：

| # | 核心问题 | 推导出的硬约束 |
| --- | --- | --- |
| Q1 | 用户如何"输入"自己？ | 需要摄像头捕捉用户形象（用于镜像）；需要麦克风捕捉语音（用于语义理解） |
| Q2 | 系统如何"理解"用户说了什么？ | 需要语音转文字（STT）→ 需要语义提取（LLM）→ 需要转化为图像生成指令（Prompt 构建） |
| Q3 | "理想世界"如何被"看见"？ | 需要 AI 生成高质量视觉内容；需要通过投影映射呈现在物理空间中 |
| Q4 | "崩塌"如何被"感受"？ | 需要实时视觉特效（裂缝、粒子、溶解）；需要空间音频配合（声音碎裂→静默） |

### （二）技术指标：

| 体验需求 | 技术指标 | 量化要求 | 来源 |
| --- | --- | --- | --- |
| 镜像效果要"像镜子" | 摄像头画面延迟 | < 100ms（否则用户会感到不自然） | 用户体验 |
| 语音交互要有"仪式感" | 端到端处理延迟 | 8-20s 可接受（不是实时对话，是"诉说"） | 艺术节奏 |
| "理想世界"要"震撼" | 图像分辨率 | ≥ 1024×1024（投影到 2m 幕布上不能模糊） | 视觉效果 |
| "崩塌"要"有层次" | 特效可分阶段 | 至少 3 个阶段（完美→裂隙→瓦解）可平滑过渡 | 艺术表达 |
| 展览要"稳定运行" | 系统连续运行时长 | ≥ 8 小时不崩溃，可自动恢复 | 展览运营 |
| 成本要"可控" | 总硬件预算 | ≤ 5 万元（教学/实验级展览） | 项目预算 |
| 部署要"可落地" | 技术人员门槛 | 1-2 名技术人员可独立完成部署 | 实施可行性 |

### （三）基本架构

| 层级 | 模块名称 | 核心职责 | 关键输入 | 关键输出 |
| --- | --- | --- | --- | --- |
| T1 | 感知输入层 | 采集用户的影像、声音、存在信号 | 物理世界 | 数字图像帧 + 音频流 |
| T2 | 视觉处理层 | 人体追踪、面部追踪、人体分割 | 图像帧 | 骨骼坐标 + 轮廓 Mask |
| T3 | 语义理解层 | 语音识别、语义提取、Prompt 构建 | 音频流 | 结构化 JSON + 图像 Prompt |
| T4 | 内容生成层 | AI 生成"理想世界"关键帧图像 | 图像 Prompt | 3 张关键帧（完美/裂隙/崩塌） |
| T5 | 空间呈现层 | 实时渲染、投影映射、空间音频 | 关键帧 + 追踪数据 | 投影画面 + 空间音效 |
| T6 | 系统编排层 | 状态机控制、模块通信、异常恢复 | 各层状态信号 | 流程控制指令 |

> **注意：T2（视觉处理）和 T3（语义理解）虽然都是"处理"，但它们处理的信号完全不同（图像 vs 音频），且使用的 AI 模型类型完全不同（计算机视觉 vs 自然语言处理），因此必须拆为独立模块。**

### （四）筛选原则

| 原则 | 含义 |
| --- | --- |
| 可实现性优先 | 能跑通 > 效果好。先验证可行性，再追求极致效果 |
| 低成本优先 | 能用电脑自带硬件就不外购；能用开源就不买商业 |
| 离线优先 | 展览现场网络不可控，优先选择可完全本地运行的方案 |
| 生态一致优先 | 同一技术栈内的组件优先组合（如 Whisper + Silero VAD 同生态） |

### ✅ 选型理由（FLUX.1 Schnell）

画质最优：1024px 投影级画质，照片级写实碾压同级别开源模型

成本为零：FP8 量化后 6-8GB 显存即可运行，无需 API 费用

部署简单：通过 ComfyUI 或直接 Python diffusers 调用，5 分钟跑通

协议友好：Apache 2.0，可自由商用

作品逻辑适配：生成→凝视→崩塌是线性过程，不需要实时流式生成；3 张关键帧 + TD 过渡完全满足

**备选方案**

显存 < 6GB：降级到 SDXL (8GB 勉强) 或 SD1.5 (4GB)

追求极致交互性：可叠加 StreamDiffusion 做实时动态层（但增加系统复杂度）

完全免费 + 完全本地：展览环境不可控网络，离线方案最可靠

### ✅ 选型理由（Silero VAD）

精度与效率的最佳平衡点：99% 检测精度 + 0.8ms 延迟 + 仅占 CPU，是工业界公认的"甜点"方案

不占 GPU：展览系统 GPU 资源优先给 FLUX 图像生成，VAD 纯 CPU 运行零冲突

与 Whisper 生态一致：同一技术栈，集成无摩擦

WebRTC VAD 的噪声问题：展厅环境有背景噪音和音乐，WebRTC 的 GMM 模型误报率高

pyannote 过重：需要 GPU 且 ~100MB，对仅需"检测说话起止"的场景过度
