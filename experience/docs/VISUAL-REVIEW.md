# 视觉与动效重构验收

本轮范围：保留原七幕会话/交互逻辑，替换背景与转场渲染。原应用仍为 Phase 1–2 模拟模式。

## 原因与修复

- 原背景只有 CSS 色块、平面窗光与等距反射线，没有可信的材质与建筑纵深。改为项目专用、无人物的共享建筑环境图（AI 制作的美术资产，不是用户输入触发的生成结果），全屏绘制在持续挂载的 Canvas 上。
- 原雾光透明度较低，动画共用若干固定节奏。改为独立时钟的呼吸、两层雾、地面反射、空间光照，叠加非同周期分量；词云改为错相错速浮动。
- 原转场通过大面积深色遮罩掩盖页面，背景尺寸改变明显。现在相机视角不切换，所有环境参数插值，前景独立淡入淡出，背景不卸载。
- 亮窗后小字和词云存在对比度不足。加入柔和、无边框的局部暗化和文字阴影。
- 低帧率下截断 delta 导致环境时钟变慢。时间按实际经过时间累计，参数平滑使用有上限的 delta；后台页面暂停，恢复不跳时。

## 启动与复现

```bash
npm ci
npm run dev
# 使用终端实际打印的端口；测试默认 5174，可设置 REVIEW_URL。
REVIEW_URL=http://localhost:5174 PLAYWRIGHT_BROWSERS_PATH=/tmp/pw-media node tests/visual-review.mjs
node tests/capture-desktop.mjs
node tests/browser.mjs
npm run build
npm test
```

`visual-review.mjs` 需要 Playwright 与可用的 FFmpeg 编码器；当前环境使用系统 Chromium、FFmpeg。记录是真实浏览器页面视频，不是静态截图拼接动画。`artifacts/refinement/` 为忽略跟踪的本地验收产物目录。

## 检查范围

| 项目 | 方法 |
| --- | --- |
| 七页背景、排版、人物 | 每页截图逐一视觉检查；共享同一图像和渲染层，不引入人物 |
| 环境持续动态 | 每页实际停留 30 秒，比较 0/5/30 秒背景像素；首页额外观察到 60 秒 |
| 机械循环 | 独立非同周期运动参数；首页比较 60 秒状态；录屏关键帧审阅。不能据有限采样证明无限时长不存在重复 |
| 黑屏、闪烁、跳变 | 背景 canvas 身份不变、时钟连续；120ms 采样亮窗亮度及截图/录屏抽帧；无法排除未采样的单帧问题 |
| 原功能 | 四种尺寸七幕走通、文本、模拟重新生成/调整、缩放、习惯多选/修改/跳过、4秒演示/重播、自述、分享确认、词云、退出清理 |
| 减弱动效 | 系统设置及按钮控制；环境时钟暂停，七幕功能仍可走通 |

## 不能宣称已验收的部分

- 原型从未接入真实 AI 文本/图像/图生视频服务，本轮也没有新增这些服务。第 03 幕仍明确为共享建筑环境演示，第 05 幕为同一环境的 4 秒光照演示，不能当作真实个性化生成。
- 无真实设备麦克风收音、识别准确率或摄像头实测。语音入口与浏览器不支持/失败时的文字退路保留。
- 截图由模型逐页审阅，录屏由关键帧与自动采样检查；未由真人连续观看、主观评估 60 秒运动节奏。
- 无真实普通笔记本 GPU 性能实测；记录的 FPS 是当前云端 Chromium 的测量，不能代表用户设备。

完整数值与录屏长度见本地 `artifacts/refinement/results.json`。最终验收说明应以实际生成的文件和运行结果为准。

## 追加修复

七幕 30 秒停留检查完成后，自动点击词云时发现整个按钮漂移会触发浏览器自动化的稳定性等待。现改为点击区域固定、内部字形漂移，悬停/键盘聚焦暂停浮动，并重新走通完整功能流程与录屏。渲染限帧增加 1ms 容差，避免 60Hz 的时间戳舍入把 30FPS 限流意外降为约 20FPS；长期采样数值保留修复前结果，不用后续短测覆盖原数据。

语音回归还发现原有 `if (!Ctor())` 会误调用浏览器识别构造器，导致点击麦克风报错；已改为检查构造器是否存在。回归使用模拟 SpeechRecognition 验证转写可编辑、拒绝权限与不支持能力三条路径；这不能代替真实麦克风收音测试。

## 本次结果

七幕每页 30 秒停留检查通过，首页额外比较 60 秒状态；复查中 335 个背景采样均非黑帧（采样点最低亮度 75.67/255）。没有 JS 页面异常。静态截图已逐页检查，三段录屏已抽帧审阅。实录尺寸 1366×768，分别为首页 12 秒、02→03 12 秒、05→06→07 14 秒；另有七页 1920×1080 静态截图。

云端长测（含像素读取开销、限帧容差修复前）约 18.7–22.7FPS；限帧修复后的无读取 10 秒短测为 26.4FPS。仍未通过真实笔记本的 30/60FPS 性能验收，不将此项标记为完成。
