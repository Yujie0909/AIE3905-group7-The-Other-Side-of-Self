## 改动前检查

- 原寄语是 `Page06Reflection.tsx` 中的独立 HTML 层，桌面主要使用 `rotate(-13deg) skewX(-6deg) scaleX(.90)`；位置按屏幕百分比而非场景坐标计算。
- 原参考 `references/page 06.png` 确实包含旧镜面文字。项目已有 `public/scenes/page06-reference-clean.jpg`，镜面区域无旧字。`ReferenceArtwork.tsx` 的既有局部遮罩隐藏原图旧字，露出去字底图。原 PNG 本身仍保留旧字，没有声称用 CSS 删除了图片中的字。
- 桌面旧色为 `#443e32`，不是纯黑，但平涂的文字与镜面反光脱节。手机使用 `#efe7d5`，也非纯白，但出现在山水上更像前景提示。
- 没有文字卡片；原有极轻微文字阴影。突兀主要来自不跟随场景坐标、缺少光学混合及局部材质关系。
- 右侧镜面内表面约为原图 x=1258–1534。暖金反光、云纹与暗灰反射真实存在，不需要重绘场景。

本轮背景文件、原始参考、去字底图、`ReferenceArtwork.tsx` 均未修改，也没有生成新纹理。

## 已实现的桌面处理

实现文件仅 `Page06Reflection.tsx`、新增 `MirrorInscription.tsx`、`mirror-inscription.css`。

1. 以原 1672×941 场景为坐标系，在有效镜面内选择四个控制点：`(1290,230)`、`(1513,187)`、`(1509,352)`、`(1287,396)`。由四角求解单应变换，生成 `matrix3d`，使三行文字顺应右侧玻璃的退远方向。
2. 文字仍是可维护的 HTML，不是写入图片。三行严格为「不必等到一切如愿，」「此刻的你，」「已经走在属于自己的路上。」字号在场景单位中为 21px，三行相同字重和字号；不突出末行。
3. 采用暖灰到低饱和蓝灰的细微字迹渐变，并在局部文字层使用 `multiply`。实际截取并比较过 `multiply`、`soft-light`、`overlay`；后两者在镜面亮部几乎不可读，因此未选用。
4. 从既有去字图读取真实的镜面明暗，转换为局部亮度遮罩，轻微调制字迹。明亮反光处适度柔化、暗反射处保留字迹。不添加虚构反射图层或明显新纹理，不靠整层极低 opacity 实现融合。
5. 边缘柔化仅 0.10 个场景像素，无 text-shadow、无背景矩形、无边框、无 backdrop-filter。整个材质合成只覆盖镜面寄语的小区域，避免影响其他 UI 的背板和文字栅格化。
6. 布局读取现有背景的 cover 比例和 object-position，跟随原图映射。ResizeObserver 只在尺寸变化时更新定位；没有动画、时钟、连续 RAF 或动态光影，离开页面时释放观察器。

字体仍继承项目现有 `--experience-font` 与其加载方式。当前仍没有可用的荆霄鹏行楷授权字体，本轮没有下载或替换字体。
