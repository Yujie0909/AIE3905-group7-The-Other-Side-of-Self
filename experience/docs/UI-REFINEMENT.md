# 七页 UI 尺寸与玻璃面板优化

仅调整既有 UI。背景、字体家族/加载、固定文案与业务逻辑不变；没有添加动画或进入新阶段。

## 修改文件

- `src/pages/page01.css`：01 的实际桌面/移动端标题与正文字号按比例缩小。
- `src/pages/static-pages.css`：02–07 各断点的标题和正文字号按比例缩小。
- `src/pages/text-system.css`：07 独立结语同正文缩小 9%；字体配置不变。
- `src/pages/ui-refinement.css`：共用玻璃表面、两处面板尺寸、习惯胶囊尺寸及正文紧凑间距。
- `src/pages/Page02Dream.tsx`、`src/pages/Page04Daily.tsx`：现有条件面板添加 `glass-dialog` 类和可访问的 dialog 语义。没有改动回调、条件或新增关闭机制。
- `src/main.tsx`：引入新的局部样式。
- `tests/ui-refinement.mjs` 与 `tests/fixtures/ui-before.json`：改动前实际浏览器尺寸基线与交互/布局回归。
- `tests/text-system.mjs`：原有标题字号基线检查同步为本轮 0.89 比例。
- 本文、README 与 `public/review/ui-refinement*` / `ui-*.jpg`：当前实际截图及验收结果；旧预览保留为历史记录。

## 共用玻璃面板

两处是原项目既有条件面板，不是新增的全屏模态流程。02 的条件仍为「短输入且尚未澄清」，长描述仍可直接进入 03；04 仍为选择习惯后点击「慢慢聊聊」进入细问。`App.tsx`、`session.ts` 和语音组件没有修改。

共用表面：`rgba(24,35,48,.28)`，`backdrop-filter: blur(12px) saturate(110%)`，1px 低透明暖白描边，24px 圆角，低强度阴影。没有新增全屏遮罩。通过实际触发后检查计算样式、z-index、父级背景和 opacity，并查看实际截图，确认中间容器透明，风景透过面板显示。

- 桌面宽度统一 +22.5%，不固定高度。02 内边距 18 → 20.5px；04 为 20 → 23px。
- 02 提问文字 13 → 15.6px（+20%），面板正文 13 → 14.95px（+15%），选择项 11 → 12.65px（+15%），原描述继续按钮 13 → 14.95px（+15%）。
- 04 细问标题 11 → 13.2px（+20%），选择项与返回/下一项按钮 11 → 12.65px（+15%）。
- 交互按钮最小高度 44px；04 选择状态继续沿用原 `aria-pressed`、答案及返回逻辑。
- 桌面 1920 的原 02 面板已经宽约 787px，因此没有套用建议的 720px 上限而缩小面板；设置 1000px 最大宽度。04 最大 1100px。
- 手机统一限制为视口宽度减 32px。在 390 宽屏幕上，两处宽 358px；优先避免溢出，未强行增加至原宽的 122.5%。04 仅设置响应式最大高度并允许内容滚动，保留原语音和输入空间；短内容仍自动适应高度。

## 04 习惯胶囊

原顺序七项不变，仍为桌面三列/手机两列。高度 7.8vh → 7.02vh，手机 49 → 44.1px；最低 44px。字号与图标 -9%，内边距和横向间距收紧；列宽由内容决定，「其他」也按内容收紧，避免沿用整列宽度。保留原圆角、玻璃背景、描边、选择反馈和数据记录。

- `tests/all-static.mjs`：原有七页完整功能及四种尺寸 28 个页面组合通过，静置画面像素一致、无 Canvas 或活动动画。
