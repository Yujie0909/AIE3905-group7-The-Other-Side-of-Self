## 字体阻塞及所需材料

在项目、工作区附件和资源目录检索 `.woff`、`.woff2`、`.ttf`、`.otf`，未找到荆霄鹏行楷；现有文档也没有该字体的网页嵌入授权。无法对不存在的字体检查元数据或字符覆盖，不把 CSS 字体名称当作字体已加载的证据。

本轮未下载任何新的字体、未加入虚假的 `@font-face` 或假装实现荆霄鹏字形。可独立完成的文字和导航已实施。`text-system.css` 将现有页面的字体配置集中到 `--experience-font`，目前仍是项目原有的衬线字体族，所有页面文字、英文、数字、输入及占位文字共用该配置。这是临时保留现状，**不是荆霄鹏行楷的替代验收**。

完成目标字体部署需要：

1. 正版荆霄鹏行楷字体文件（优先 WOFF2；TTF/OTF 也可以在授权允许时转换）。
2. 可确认的网页嵌入/自托管授权或购买许可，适用当前 GitHub Pages 网站；若不允许在公开源代码仓库存储字体，需要相应的部署约束。
3. 收到后核对字体 family、版本、字重、厂商与许可元数据；检查本轮固定文案、数字、标点、英文和动态输入字符覆盖，再加载、截屏和验收。当前尚未执行这些检查。
